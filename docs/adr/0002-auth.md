# ADR 0002: Auth

**Status**: Accepted
**Date**: 2026-04-13

## Decision

Auth.js v5 magic links via Resend. Six users seeded directly in the database. No
public signup. Login flow: enter email → if allowlisted, send magic link → otherwise
silently no-op (don't reveal whether email exists).

One boolean `is_editor` on the users table grants itinerary edit rights. No roles
table, no permissions matrix.

## Why

Six known people. Passwords are more work and worse UX than magic links. Seeding users
directly is simpler and more secure than a signup flow we'd then have to gate. The
single `is_editor` flag is the minimum viable authorisation for "Ozzie can edit, others
can't."

## Alternatives considered

- **Shared password**: no way to attribute comments or votes, so votes are meaningless
- **GitHub OAuth**: fine, but not everyone in the group has or wants a GitHub account
- **Full roles system**: overkill for six people and one permission
